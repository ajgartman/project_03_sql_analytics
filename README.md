SQL Analytics Tier 1 / Project 03

Hello there! My name is Andrzej and here is my SQL practice.

Description:
SQL practice repo using a synthetic manufacturing plant database. 
Built to practice JOINs, CTEs, and window functions on data with realistic messiness (NULLs, sensor dropouts, machines with no maintenance history) — not a clean tutorial dataset.

Fake data - generated by the LLM.

Tasks: 

 `01_oee_by_line.sql` | Which production lines hit planned output most consistently? |
 `02_drift_detection.sql` | Which machines show rising temperature trend vs. their own baseline? |
 `03_defect_rate_by_shift.sql` | Does defect rate actually differ by shift? |
 `04_maintenance_cost_pareto.sql` | Do a small number of machines drive most maintenance cost? |
 `05_maintenance_gap_vs_defects.sql` | Do longer gaps since last maintenance correlate with more defects? |
 `06_operator_consistency.sql` | Which operators are most consistent vs. most volatile in output accuracy? |
 `07_downtime_cost_by_age.sql` | Does maintenance cost rise with machine age? |
 `08_sensor_anomalies.sql` | Which sensor readings are outliers relative to that machine's own baseline? |
 `09_duration_vs_severity.sql` | Does work order duration relate to defect severity? |
 `10_cross_plant_comparison.sql` | How do plants compare on output accuracy and defect rate? |
